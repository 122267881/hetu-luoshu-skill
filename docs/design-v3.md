# 河图洛书 Skill 3.0 设计

## 根问题

用户需要的不是更长的河洛知识说明，而是一套能够处理真实需求的统一工作系统：任何问题先分类、识别风险和证据需求，再进入诊断、决策、设计、执行、验证与复盘；无法安全解决的部分必须交给专业系统。

## 架构

1. **知识层**：经典、历史、传统、数学和现代应用使用 P/H/T/M/A/U 分层。
2. **通用入口层**：16 个现实领域、10 种问题类型、3 个支持等级和 Trust Gate。
3. **河图定体层**：中心、本体、资源、五组要素、启动与完成条件。
4. **洛书定用层**：态势、对位张力、运行、失衡和反馈变化。
5. **决策层**：选项、标准、方向、权重、贡献和敏感性。
6. **执行层**：负责人、交付物、依赖、检查点、指标和回滚。
7. **进化层**：从结果中提炼成功不变量、失败规则、案例和测试。
8. **安全层**：高影响专业接管、外部材料无指令权和零执行安装器。

## 关键取舍

- “通用”表示统一入口与流程，不表示无所不知或保证成功。
- 现代问题解决是 A 类方法论，不冒充古代固定原义。
- 领域适配由 JSON 数据驱动，主循环保持稳定。
- 缺少事实时生成取证计划，不生成虚假根因。
- 高成本方案从小范围、可回滚试点开始。
- 测试先于实现；新增分类、求解和决策能力均有失败基线与回归用例。
