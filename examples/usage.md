# 使用示例

## 示例一：大白话科普

输入：

```text
使用 $hetu-luoshu：给完全不懂国学的人解释河图洛书。
```

预期：

- 一句话先区分“河图定生成、洛书定运行”。
- 给出河图五组数字与洛书九宫。
- 算出 25、30、55、15、10。
- 把伏羲、大禹标为传说，把宋代图式史标为历史研究。
- 不输出吉凶预测。

## 示例二：产品系统建模

输入：

```text
使用 $hetu-luoshu：用河图洛书重新设计一个 AI 内容生产系统。
```

预期：

- 河图：中央价值、五类能力、每类启动/完成条件。
- 洛书：九宫角色、中心原则、对位制衡。
- 每个类比绑定 KPI、失败信号和停止条件。
- 标注 A 类现代应用，不宣称来自古代原义。

## 示例三：内容审计

输入：

```text
使用 $hetu-luoshu：审查“所有中医理论都直接来自河图洛书”这句话。
```

预期：

- Trust Gate: WARN。
- 说明它是过强概括。
- 给出更稳妥改写。
- 要求专门医学史证据，不能只用象数对应。
