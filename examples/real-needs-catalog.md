# 河图洛书 Skill 可处理的真实需求目录

以下是“结构化解决”而非“神秘预测”。

1. 把模糊想法变成可验证产品。
2. 比较多个商业化路径。
3. 为项目拆范围、里程碑、责任和风险。
4. 排查系统故障并形成复盘。
5. 设计企业 AI Agent、知识库和自动化协作。
6. 规划课程、研究和知识体系。
7. 制定内容定位、选题、渠道和转化实验。
8. 处理个人目标冲突和优先级。
9. 准备困难沟通、谈判和关系边界。
10. 设计非医疗的作息或专注习惯实验。
11. 规划预算、成本和资源分配，不做价格预测。
12. 建立团队岗位、流程、审批和会议节奏。
13. 审计方案中的权限、安全、合规和责任。
14. 生成创意方向，并用现实标准筛选。
15. 把跨领域复杂问题拆成可路由的子问题。

每个案例都使用：目标 → 边界 → 结构 → 态势 → 张力 → 方案 → 行动 → 验证 → 进化。
