# 河洛九步现实问题解决引擎

## 定位

这是把“河图定体、洛书定用”转化为现代问题解决协议的 **A 类方法论适配**。它不声称古代河图洛书原本包含现代项目管理、商业分析或工程方法，也不保证解决所有问题。

价值在于：任何需求先进入同一个结构化入口，再判断是否可解决、需要什么证据、由谁执行、怎样验证、何时停止或专业接管。

## 九步

1. **立极**：明确目标、成功标准、非目标和截止条件。
2. **定界**：确定系统边界、时间范围、对象、利益相关者和权限。
3. **定体**：识别稳定结构、资源、约束、依赖和不能破坏的底线。
4. **定势**：记录事实、当前状态、阶段、趋势、不确定性与假设。
5. **定衡**：识别主要矛盾、对位指标、收益与代价、短期与长期张力。
6. **定策**：生成备选方案，寻找高杠杆动作，比较成本、价值、速度和风险。
7. **定行**：定义下一步、负责人、依赖、里程碑、交付物和沟通机制。
8. **定验**：定义基线、指标、实验、证据门槛、失败信号和停止条件。
9. **定变**：按反馈继续、调整、回滚、升级或沉淀为新规则。

## 九宫工作台

“中宫”只放一个核心目标，其余八格围绕它工作：边界、结构、态势、张力、方案、行动、验证、进化。九宫是现代工作台，不是传统洛书方位配属的历史断言。

## 最小输入

```json
{
  "goal": "希望改变的结果",
  "context": "当前事实与背景",
  "constraints": ["限制"],
  "resources": ["可用资源"],
  "stakeholders": ["相关角色"],
  "success_metrics": ["可观察结果"]
}
```

缺少 goal 时不得直接给大方案。缺少事实时，输出假设与取证计划，不能把猜测包装成诊断。

## 支持等级

- `supported`：可以提供结构化方案、执行计划和验证闭环。
- `assisted`：可以辅助梳理，但关键数据、现实执行或专业判断在外部。
- `restricted`：医疗诊断、个性化高风险金融指令、法律定论、危机处置、确定性命理等不得由本 Skill 作结论；必须专业接管。

## 完成定义

一个问题不因“给出很多建议”而解决。至少需要：明确目标、可执行下一步、负责人或执行主体、验证指标、失败信号、复盘时间和回滚条件。
