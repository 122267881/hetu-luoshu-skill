# 决策与实验协议

## 决策矩阵

当存在多个可行选项时，使用加权标准，而不是凭象数直接判断。

```json
{
  "criteria": [
    {"name": "客户价值", "weight": 5, "direction": "max"},
    {"name": "实施成本", "weight": 3, "direction": "min"}
  ],
  "options": [
    {"name": "方案A", "scores": {"客户价值": 8, "实施成本": 4}}
  ]
}
```

分数只能表达当前判断，不是真理。必须保留：评分依据、未知项、敏感性警告和现实验证步骤。

## 对位制衡

每个主要指标至少找一个可能被牺牲的对位指标，例如：

- 增长 ↔ 现金消耗
- 速度 ↔ 质量
- 自动化 ↔ 可控性
- 收入 ↔ 客户成功
- 个性化 ↔ 维护成本
- 短期结果 ↔ 长期能力

不得只优化单个数字。
