# 河图洛书术语地图

## 使用方法

先判断术语属于哪一层，再解释含义。相同词语在经典、宋代易图、后世术数和现代类比中的含义可能不同。

| 层级 | 代表术语 | 解释重点 | 常见错误 |
|---|---|---|---|
| 经典文本 | 河图、洛书、圣人则之 | 文本实际说了什么 | 把一句文字直接等同今行图式 |
| 宋代图式 | 刘牧、易数钩隐图、河洛九十之争、朱子重构 | 图式何时出现、如何改名与定型 | 把宋代图式倒推为考古实物 |
| 传统象数 | 天地之数、生数成数、五行方位、九宫、中五立极 | 体系内部如何解释数与象 | 把传统分类冒充实验科学 |
| 数学结构 | 三阶幻方、和数十五、对位和十、旋转镜像 | 可重复计算的性质 | 从对称性跳到宇宙因果 |
| 接受与衍生 | 八卦、洪范九畴、九宫术数、中医、历法、风水 | 后世如何吸收、重构和应用 | 宣称所有体系单线直接源于河洛 |
| 现代应用 | 体用、本体、运行、制衡、指标 | 如何转成可验证分析框架 | 只做数字贴标签，没有现实变量 |

## 核心词关系

```text
经典“河图/洛书”观念
        ↓ 历代解释
汉唐：河图—八卦、洛书—九畴等范式
        ↓ 宋代易图创造与争论
刘牧图式 → 河洛九十之争 → 朱子重构与定型
        ↓ 后世接受
象数易学 / 九宫 / 术数 / 方位时间解释
        ↓ 现代再阐释
文化研究 / 数学教育 / 系统建模
```

## 快速辨析

- **河图**：传统通行图式用一至十和五组相差五的配对组织数、方位和五行。
- **洛书**：通行九宫数阵使用一至九，标准排列是正常三阶幻方。
- **先天/后天**：是后世常用的体用解释，不应强行当作所有早期文本的原义。
- **图/书**：经典中的名词不自动证明现行点阵图已经以相同形式存在。
- **象数**：以象、数及其关系解释《易》与宇宙秩序的传统方法，不等同现代数学或自然科学。
