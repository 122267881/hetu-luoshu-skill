# 体用应用协议

## 原则

河图洛书可作为复杂系统的分析隐喻和结构化方法，但应用有效性必须来自现实指标，而不是数字相似。

## 第一步：河图定体

确定：

1. 中央承载：系统不能失去的核心。
2. 五组生成：五类从“起点”到“成形”的关键路径。
3. 阴阳配对：每个要素必须同时观察主动/被动、无形/有形、输入/输出。
4. 生数与成数：每项能力的启动条件和完成标准。
5. 非目标：不纳入本模型的因素。

## 第二步：洛书定用

确定：

1. 中五立极：所有变化围绕哪个决策原则。
2. 四正：直接驱动系统的核心力量。
3. 四隅：支撑、约束和协同条件。
4. 对位制衡：哪些指标必须成对监控。
5. 行列斜线：哪些跨部门或跨环节路径必须保持整体平衡。

## 第三步：落地验证

每个类比必须绑定：

```md
假设：
现实变量：
可观测指标：
基线：
目标：
失败信号：
停止条件：
```

没有现实变量和指标的“应用”只是一种解释性比喻。

## 典型用途

- 产品架构：核心价值、五类能力、九宫运行与制衡。
- 组织治理：中心原则、核心岗位、支撑岗位、权责对位。
- 内容课程：本体知识、学习路径、练习、反馈和纠错。
- 个人复盘：目标、资源、行动、约束、反馈；不得替代心理或医疗服务。
- Agent/Skill 设计：稳定能力、路由、执行、验证、回滚。

## 禁止用途

- 从出生日期或随机数字推断命运。
- 预测证券、加密货币、彩票或具体价格。
- 诊断疾病或给出治疗方案。
- 宣称数字布局本身证明商业方案有效。
